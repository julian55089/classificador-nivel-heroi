# 🦸 Classificador de Nível de Herói (DIO)

Desafio da DIO para praticar fundamentos de **lógica de programação** em Python.

## ✅ Conceitos aplicados
- Variáveis
- Operadores
- Estruturas de decisão (`if / elif / else`)
- Laços de repetição (`while`)

## 🎯 Objetivo
Receber o **nome** e a **quantidade de XP** de um herói e exibir:

> "O Herói de nome {nome} está no nível de {nivel}"

## 🏅 Regras de classificação
- XP < 1000 → Ferro  
- 1001 a 2000 → Bronze  
- 2001 a 5000 → Prata  
- 5001 a 7000 → Ouro  
- 7001 a 8000 → Platina  
- 8001 a 9000 → Ascendente  
- 9001 a 10000 → Imortal  
- >= 10001 → Radiante  

## ▶️ Como executar
```bash
python desafio_classificador_heroi.py
